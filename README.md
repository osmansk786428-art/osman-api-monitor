# ⚔️ OSMAN CYBER LAB — API MONITOR V7.1

🐺 RGB RAINBOW EDITION

Python-based API monitoring toolkit.

## Requirements

- Python 3.10 or newer
- Python standard library only; no third-party packages currently required

## Run on Termux / Kali Linux / Linux

```bash
python3 api_monitor_v7.0.py
```

Or use the launcher on systems with Bash:

```bash
chmod +x run.sh
./run.sh
```

## Security

Only test APIs you own or are authorized to access.
Never publish API keys, passwords, tokens, or private reports.
